# Competitor Analysis

Same dimensions, same scoring, every competitor — so differences are
signal, not mood. Run by competitor-agent.

## Dimensions & what to actually check

| Dimension | Check |
|---|---|
| UX | Walk the primary conversion path; count steps, dead ends, friction |
| Visual hierarchy | Squint test on key pages; is the job of each page obvious |
| Content | Depth, specificity, credibility signals, staleness |
| SEO | Titles/descriptions/H1s on key pages, schema presence, sitemap/robots sanity |
| Speed | Lighthouse mobile run where possible (record numbers, not impressions) |
| Accessibility | Quick audit: keyboard walk, contrast spot-checks, alt text sampling |
| Mobile | The conversion path at 375px; nav, forms, CTA reachability |
| Conversion design | CTA clarity/placement, trust elements, form friction, pricing legibility |
| Interaction | Quality of states/transitions; jank; delight that serves |

## Scoring

1–5 per dimension per competitor, each score with a one-line
justification and marked **[M]** measured or **[J]** judged. No empty
cells — "N/A" needs a reason.

## Outputs

1. The matrix.
2. **Takeaways**:
   - Category strengths → patterns to learn (abstracted).
   - Category weaknesses → differentiation openings.
   - Table stakes → what we must match to be credible.
   - Threats → who's moving fast and where.
3. **Implications** addressed to: product-director, design-director,
   seo-agent, growth-agent.

## Rules

- Compare money paths, not just home pages.
- Desktop AND mobile viewport for every competitor.
- Nothing observed is copied — patterns only (see research-intelligence).
- Date-stamp the analysis; competitor sites change.
