# Reference: Design Principles Quick Sheet

Working distillation for design reviews. The law is DESIGN.md; this is
the pocket version with the numbers.

## Typography

- Modular scale ratios: 1.2 (minor third, dense UIs) · 1.25 · 1.333
  (perfect fourth, editorial) · 1.5 (dramatic, marketing).
- Body: ≥16px; line-height 1.5–1.7 body, 1.1–1.3 display.
- Measure: 45–75 characters; never center long-form text.
- Hierarchy needs ≥2 signals (size + weight/color/spacing), not size alone.

## Spacing

- One scale: 4-base (4/8/12/16/24/32/48/64/96) or 8-base.
- Related closer than unrelated — proximity is grouping.
- Section rhythm: consistent vertical cadence, broken only for emphasis.

## Color

- Roles, not moods: dominant / supporting / accent / semantic / neutrals.
- ~60/30/10 proportion instinct; accent scarce.
- Every text pair contrast-checked (see accessibility reference).
- Grayscale test: hierarchy must survive without color.

## Composition

- The squint test: 1st/2nd/3rd eye-landing matches the page's job.
- Alignment is invisible until broken; break the grid only on purpose.
- Whitespace has jobs: grouping, breathing, emphasis.
- Asymmetry with intent beats symmetric sameness (slop signature).

## Motion

- Feedback 120–200ms · transitions 200–400ms · narrative earns more.
- Ease-out for entrances, ease-in for exits, standard curve for moves.
- Reduced-motion path always.

## The five questions of a review

1. What is this page's one job — does the hierarchy serve it?
2. What can be deleted with no loss? (Delete it.)
3. Are all states designed?
4. Does it survive 320px and 200% zoom?
5. Would the logo-swap test fail? (It must.)
